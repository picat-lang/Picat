Version 4.0b11 (10/23/2026)
=================================
+ Updated the parser to allow higher-order variable calls of the form S(A1,A2,...,An), where S is a variable at compile time and refers to a callable term at runtime. Picat translates this notation into a call or apply invocation, depending on the context. Higher-order calls can also be module-qualified: m.S(A1,A2,...,An) invokes the function or predicate defined in module m whose symbol is referenced by S.

+ Updated the parser and preprocessor to allow anonymous function and predicate definitions.

    anonymous_function ->
        "(" lambda_parameters "->" expression ["," body] ")"

    anonymous_predicate ->
        "(" lambda_parameters "=>" body ")"    

+ Updated the parser to allow terms of the form +(num) and -(num) (in early versions, +(num) and -(num) are always numbers).

+ Updated the planner module to allow a planning model to be reused with different initial states.

+ Updated "table.c" to fix potential memory leaks.

+ Added the reset_store built-in to the constraint modules to clear the constraint store, allowing multiple constraint problems to be posted and solved sequentially.

+ Replaced the propagators for the table_in and table_notin constraints in the cp module.

+ Improved the hcp, scc, scc_d, acyclic, acyclic_d, path, and path_d graph constraints.

+ Fixed a bug in delete/2 in the ordset module.

+ Added the binom(N,K) function to the math module.

+ Reimplemented big-integer multiplication and division, making both operations more than 10 times as fast.

+ Changed the command used to invoke the Cbc mip solver to:

    cbc __tmp.lp -solve -solution __tmp.sol

+ Removed the C interface to SCIP. Picat now invokes SCIP with the following command:

    scip -q -c "read model.lp optimize write solution model.sol quit"

+ Improved the parser's error messages for unmatched quotation marks in strings.

+ Changed the debugger to read commands from the console so that it works even when stdin is redirected to a file.

+ Added a preprocessing algorithm for the hcp constraint.

+ Added an algorithm for decomposing PB constraints that exploits the presence of at-most-one constraints.

+ Added hybridization strategies for combining BDD, binary-adder, and Espresso encodings of PB constraints.

+ Added support for specifying the objective to be minimized or maximized in the sat module's solve/2 predicate as a bit-vector.

+ Improved the implementation of the branch-and-bound algorithm in the SAT compiler.

+ Adopted a BDD-based encoding for medium-sized PB constraints.

+ Adopted a dynamic-programming encoder for translating SCM constraints into SAT, providing efficient, near-optimal encodings.

+ Added the mmin and mmax table modes to instruct Picat to table all optimal answers.

+ Changed best_plan_nondet to use depth-unbounded search to find all optimal answers. Its implementation uses the mmin table mode.

+ Refined the BDD encoding for table constraints.

+ Extended aggregate functions in arithmetic constraints, including sum(E), min(E), max(E), prod(E), and count(V,E), to support nested collections in E.

+ Extended aggregate functions in arithmetic expressions, including sum(E), min(E), max(E), and prod(E), to support nested collections in E.

+ Updated X**0 to return 1 when X is a big integer.

+ Improved the compiler to support huge rules containing tens of thousands of subgoals and variables.

+ Added array comprehensions. An array comprehension {E : Iterator, ...} is equivalent to to_array([E : Iterator, ...]).

+ Added the insert_ordered_down(OrderedList,Elm) built-in function.

+ Added best_plan_nondet/2-4 to the planner module to return multiple plans through backtracking.

+ Added the datetime module with the following functions:
    current_datetime()
    current_date()
    current_day()
    current_time()

+ Added the -g InitGoal command-line option to execute a specified goal instead of the default main/0 or main/1.

+ Changed redundant commas and semicolons in if-then-else constructs and loops to produce warnings instead of errors.

+ Changed the evaluation_error(undefined) exception to evaluation_error(undefined,error_value).

+ Changed the evaluation_error(zero_divisor) exception to zero_divisor.

+ Improved the SAT compiler.

+ Added the following global constraints to the cp and sat modules:
    matrix_element(M,I,J,V)
    scalar_product(A, X, Product)
    scalar_product(A, X, Rel, Product)
    all_different_except_0(Xs)
    exactly(N, X, V)
    at_most(N,X,V)
    at_least(N,X,V)

+ Changed the "picat File" command to return 1 if a runtime or syntax error occurs while executing File, and 0 otherwise.

Version 0.9 (March 1, 2015)
=================================
+ Extended table constraints to accept arrays as tuples, as in table_in({V1,V2},[{1,2},{2,3}]). The tuple form (a1,a2,...,an) remains supported but is obsolete.

+ Adopted Espresso to generate compact CNF code for domain, table, element, and regular constraints.

+ Removed SAT support from the MSV version. Windows users must use the Cygwin version for SAT support.

+ Improved the error message for a Prolog-style if-then construct (A -> B) with no else branch.

+ Fixed bugs, including those reported by Sergii Dymchenko.

+ Removed all global constraints from the mip module, leaving support for linear constraints only.

Version 0.8 (January 24, 2015)
=================================
+ Updated the spacing and parenthesis rules for printing expressions.

+ Significantly improved the SAT compiler, especially its handling of arithmetic, reified arithmetic, table, cumulative, and all_different constraints.

+ Extended the SAT solver to support multiple calls and backtracking within one program execution.

+ Added support for reifying count(V,L,Rel,Count) in the cp, sat, and mip modules.

+ Added the dump(File) option to solve/2 in the sat module to write the generated CNF code to File.

+ Updated cp/2 in the os module to prevent a file from being copied onto itself.

+ Added type checking to several built-ins.

+ Added bool_dvar(X) to the basic module and nvalue(N,L) to the sat and cp modules.

+ Improved the evaluation of tabled programs that require only one answer.

Version 0.7 (November 13, 2014)
=================================
+ Changed insert_ordered(L,T) to require L to be a proper list.

+ Adopted the two-product encoding for the at-most-one constraint in the sat module.

+ Improved the efficiency of translating X #=> Y in the sat module.

+ Added len(Term) as an alias of length(Term).

+ Added the len attribute as an alias of length, as in [1,2].len = L.

+ Changed the default labeling strategy for max/min back to maxof/minof. Version 0.6 used maxof_inc/minof_inc.

+ Disallowed dot and index notation in objective expressions for minof, maxof, minof_inc, and maxof_inc.

+ Improved the debugger.

+ Fixed a bug in read_file_lines(File) that affected reading UTF-8 characters.

+ Standardized the behavior of mod/2 and div/2 across the cp, sat, and mip modules. The // operator is equivalent to div.

Version 0.6 (August 15, 2014)
=================================
+ Improved the SAT compiler's handling of reified constraints, X #=< Y, and other constraints.

+ Added a decomposition algorithm for the cumulative constraint.

+ Added a linear-time algorithm for vars(Term)=Vs.

+ Added minof_inc/2-3 and maxof_inc/2-3 to the basic module.

+ Extended maxof/2-3, minof/2-3, maxof_inc/2-3, and minof_inc/2-3 to accept real-number objective expressions.

+ Extended nth(I,S,V) to allow S to be a structure, including an array.

+ Changed negative numbers such as -1 to be treated as numbers even in patterns, so integer($-1) succeeds.

Version 0.5 (July 16, 2014)
=================================
+ Improved the SAT compiler.

+ Standardized the behavior of mod/2 and div/2 across the cp, sat, mip, and basic modules.

+ Improved the implementation of X #= max(L) and X #= min(L) in the cp module.

Version 0.4 (July 2, 2014)
=================================
+ Added get_table_map() to the basic module. A table map is stored in the table area, and both its keys and values are hash-consed.

+ Added is_tabled_state(S) and current_resource_plan_cost(Amount,Plan,Cost) to the planner module.

+ Added the subcircuit/1, lex_le/2, lex_lt/2, and regular/6 global constraints to the cp and sat modules.

+ Reimplemented cp/2 for copying files in the os module.

+ Added the table_blocks statistics flag.

+ Made several significant improvements to the SAT compiler.

+ Fixed bugs, including those affecting neqs/1 and inserting non-ground pairs into the global map.

Version 0.3 (May 23, 2014)
=================================
+ Added the mip module to connect Picat to GLPK. In addition to the integer-domain linear constraints supported by cp and sat, mip supports real-domain linear constraints. Example MIP models are available at http://www.hakank.org/picat/#mip.

+ Made solve(Options,Vars) nondeterministic in the sat and mip modules.

+ Added the rand, rand_var, and rand_val labeling options to the cp module.

+ Added support for the reifications B #<=> X :: Y and B #<=> X notin Y in all three constraint modules.

+ Changed the ++ operator to be right-associative.

Version 0.2#1 (April 1, 2014)

    new_list(N,InitVal) = new_list(N,InitVal).

+ Fixed bugs affecting big-integer arithmetic, FD backtrack statistics, fd_degree, between/3, and other functionality.
